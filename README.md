# Web Experiment 02 - 注册表单页面

## 实验内容
这次实验我做了一个用户注册页面，主要练习了 HTML 里的表格、表单和列表这几个标签，还有一些语义化标签的使用。

## 页面里有什么
- 一个注册须知的表格，用了 colspan 合并单元格
- 一个完整的注册表单，包含用户名、密码、性别、出生日期、邮箱、手机号、兴趣爱好、头像上传、年级选择、个人简介这些输入项
- 两种 label 的写法（for 关联和包裹式）
- 有序列表写注册步骤，无序列表写温馨提示
- 用 JS 在控制台打印填写的注册信息

## 用到的知识点
- 语义化标签：header、main、footer
- 表格：table、thead、tbody、tr、th、td
- 表单：input 的各种类型（text、password、radio、checkbox、date、email、tel、file）、select、textarea、button
- 列表：ol、ul、li
- 简单的 JavaScript 获取表单数据

## 我的感受
这次实验比第一次难一点，特别是表单的各种控件容易搞混，就比如 radio 和 checkbox 的区别。表格合并单元格一开始也写错了，后来查了一下才搞清楚 colspan 的用法。整体做下来对 HTML 的标签熟悉了很多，也知道了怎么把表单里的数据打印到控制台看。
